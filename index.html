About Syntax Master AI

Syntax Master AI is a bilingual (English + Bengali) Progressive Web App designed for West Bengal Board students (Classes IX–XII) to master English Syntax based on Articles 451–489 and Exercises 65–70.

Features

  • Complete bilingual lessons covering all rules
  • Interactive question bank with click-to-reveal answers
  • Explain My Mistake system
  • Textbook Exercises 65–70 kept separate
  • Exam mode, Quick Quiz, Mistake Book, Smart Revision
  • Progress tracking (offline)
  • Voice learning (Web Speech API)
  • Teacher Zone for creating questions
  • Installable PWA — works offline

How to use

  1. Start with Learn Syntax — read rules in EN / BN / BOTH
  2. Practise in Practice Zone or do textbook exercises
  3. Use Exam Mode for timed tests
  4. Review mistakes and revise weak topics
  5. Install the app for offline use
